# Sentence illustrations (prototype)

Hand-drawn, animated illustrations that act out each read-along sentence, timed to the
sentence's aligned word timestamps (the same `words[]` the app already uses for highlighting).

**Status (2026-11-26):** *The Fox and the Grapes* (6 sentences) is illustrated and wired into the
tutor app's reader. The other stories need their characters drawn first.

## Layout

```
scenes/                       SOURCE OF TRUTH
  sketch.js                   drawing kit: fox, trees, sun, trellis, grapes, bubbles; walk/jump/look helpers
  fox.js                      one scene per sentence of "The Fox and the Grapes" (window.SCENES.fox)
  panel.js                    in-app host: loadScene(story, index, words, end) + seekScene(t)
fox-and-the-grapes/           HyperFrames preview project (all sentences back to back; optional MP4)
```

## In the app (built 2026-11-26)

- Tap a sentence: it scrolls to the top and an illustration panel opens under it (`tutor-app/src/illustrations/SceneView.tsx`).
- The Reader's existing 50 ms reading tick calls `seek(player.currentTime)`, so the drawing follows the
  narration at every speed. The panel holds its last frame during the question and answer. Tapping the panel replays the sentence.
- Scenes run in `react-native-webview` from one offline HTML string, `tutor-app/src/illustrations/sceneHtml.ts`,
  generated by `npm run illustrations` (bundles gsap + scenes/*.js). Re-run it after editing anything in `scenes/`.
- Only stories listed in `STORIES` in `tutor-app/scripts/build-illustrations.mjs` get a panel. Others read as before.
- Illustrations only, no vocabulary labels (product decision 2026-11-26).

## Scene contract

```js
SCENES[storyId][i]({ tl, L, w, S, end })
// tl  GSAP timeline      L  <g> to draw into      S  window.Sketch
// w("word", nth)  start time of that word in the sentence audio      end  sentence end
```
The panel's viewBox is `-20 420 1000 600` (wide). Keep scene action inside x 0-960, y 440-1000.

## Adding a story

1. Add characters/props to `scenes/sketch.js`, then write `scenes/<storyId>.js` with one scene per sentence keyed to `w("word")`.
2. Add the id to `STORIES` in `tutor-app/scripts/build-illustrations.mjs` and run `npm run illustrations`.
3. Optional: preview all sentences in HyperFrames (copy the story's audio + timings like `fox-and-the-grapes/`).
